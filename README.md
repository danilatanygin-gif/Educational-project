# Погода
- Описание: Учебный проект по работе со сторонними API. Пользователь вводит название города и видит текущую погоду и прогноз на 5 дней. Данные загружаются асинхронно с внешнего сервиса и отображаются на странице без перезагрузки.
- Стек: HTML, CSS, JavaScript, PHP, MySQL.
- Инструменты будут дополнятся. 
- Запуск: производиться путем открытия index.html в браузере.
