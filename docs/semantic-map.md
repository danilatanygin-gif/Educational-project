# Semantic  map
---

| Блок макета                  | Назначение                | HTML        | Обоснование                                                                                                      |
| ---------------------------- | ------------------------- | ----------- | ---------------------------------------------------------------------------------------------------------------- |
| "Бургер"                     | Скрывает навигацию        | `<button>`  | Интерактивный элемент, который при нажатии открывает скрытое меню                                                |
| "Основная навигация"         | Главные ссылки сайта      | `<nav>`     | Основной ориентир страницы.                                                                                      |
| Логотип                      | Ссылка на главную         | `<a>`       | Переводит пользователя на главную страницу                                                                       |
| Настройки региона            | Выбор языка и валюты      | `<div>`     | Объединяет интерактивные селекторы, выполняющие роль переключателей контента                                     |
| Пользовательские инструменты | Быстрые действия          | `<div>`     | Панель иконок (поиск, корзина)                                                                                   |
| Первый экран (Hero)          | Главное промо-предложение | `<section>` | Смысловой раздел с главным баннером коллекции                                                                    |
| Карусель категорий           | Выбор категорий товаров   | `<section>` | Крупный смысловой блок с перечнем разделов каталога.                                                             |
| Форма подписки               | Сбор email-адресов        | `<form>`    | Интерактивная зона с инпутом                                                                                     |
| Меню в подвале               | Вспомогательные ссылки    | `<nav>`     | Раздельные навигационные блоки («Компания», «Покупателю»), каждый из которых имеет свой уникальный ID-заголовок. |
| Контакты                     | Обратная связь и соцсети  | `<address>` | Семантический тег для разметки контактной информации.                                                            |
